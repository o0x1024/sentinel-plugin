## Preferred reasoning moves

When summarizing or generating adjacent original text, prefer these moves:

- `Split the term`: show that one word hides multiple relations.
- `Re-anchor the context`: ask which country, class, institution, or profession the argument actually belongs to.
- `Lower the abstraction`: replace slogan with mechanism.
- `Pick one concrete example`: use a small scene to pin the judgment down.
- `Close hard`: end with a sentence that removes escape hatches.

## Sentence-shape guidance

These are abstract shapes, not copy templates.

- Start with a claim, not throat-clearing.
- Move quickly from concept to example.
- Keep modifiers sparse.
- Let the final sentence carry the weight.

Good:

- short;
- exact;
- example-backed;
- mildly cutting when necessary.

Bad:

- lyrical imitation;
- decorative metaphors everywhere;
- deliberate catchphrase cosplay;
- whole-paragraph mimicry.

## Safe original writing workflow

If the user asks for original writing influenced by this material:

1. State the topic in plain terms.
2. Decide which confusion to correct.
3. Choose one reasoning move.
4. Add one concrete example.
5. End with a terse judgment.
6. Remove any phrase that sounds recognizably lifted from tombkeeper.

## Refusal redirect

If the user asks:

- `模仿 tombkeeper 写一段`
- `按 tombkeeper 口吻骂人`
- `复刻这种语气`

Redirect to:

- `我可以保留这些抽象特征：简洁、先拆概念、用例子钉结论、少抒情、收尾更硬。`

## Evaluation checklist

Use this before returning original text:

- Does it stand on its own without leaning on a famous line.
- Does it explain a confusion instead of only输出态度.
- Does it avoid sounding like a stitched-together tombkeeper parody.
- Does it keep the useful reasoning while dropping the identity mimicry.
